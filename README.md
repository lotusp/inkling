# Inkling

面向个人中文技术作者的思考与写作伙伴，帮助作者整理实践、形成和检验判断、表达个人洞见，并积累可以再次使用的知识。

当前处于产品设计阶段，尚未实现应用。

当前定位以辅助个人思考、形成判断和表达洞见为核心；MVP 优先验证思考与写作协作，博客交付逐步接入。
