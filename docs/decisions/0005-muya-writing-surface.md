# DEC-0005 · V1 正文编辑器采用 Muya

2026-11-20 已接受，适用于 C04 技术编辑器。作者在体验 MarkText 内核试写页后确认选型，希望保留按需显示的图片操作，并让表格、图标和流程图融入现有稿纸。

采用 `@muyajs/core@0.2.0` 提供正文、表格、行内工具和图片缩放。图片插入借鉴 Milkdown 的交互方式，支持选文件、粘贴截图和拖入；点选后可更换文件、修改说明。运行时由 Muya 持有同一份选区、撤销栈和正文状态。V1 尚未发布，正式替换时可以删除被取代的编辑逻辑。

Muya 的表格、浮层与流程图使用稿纸色板，图片内容保留原色。试写页和正式文章分别验收。正式接入须贯通编辑会话、历史修订、只读和工作空间附件。若引擎在中文组合输入、离线预览或保存恢复上出现无法解决的缺口，复审选型。[C04 设计](../../openspec/changes/complete-technical-editor/design.md)
