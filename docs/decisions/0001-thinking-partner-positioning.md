# DEC-0001 以个人技术思考与写作协作为产品核心

状态：已明确方向。记录日期：2026-11-13。决定依据：作者在本项目讨论中明确要求辅助真正思考、整理并表达个人洞见，并排除当前阶段的追热点、热门文章仿写和快速仿写方向。此记录不代表具体技术方案已获确认。

## 背景

前期比较覆盖营销、小说、研究和博客工具。随着作者明确目标，竞争基线需要转向思考、知识组织、协作编辑以及通用 Agent 的组合。相关依据见[行业调研](../research/industry-overview.md)。

## 选择

Inkling 当前以个人中文技术作者为首要用户，帮助其探索问题、形成和检验判断、保留原意并积累理解。博客和技术社区仍是交付渠道，优先级服从思考与写作闭环。

## 备选方向与取舍

营销内容生产可以强调产量与传播，但不符合当前明确需求。通用文章生成覆盖广，难以聚焦个人判断。通用 Agent 加现有笔记工具可以满足部分需求，继续保留为验证基线和潜在集成路线。

## 影响与代价

MVP 增加观点、依据、反例和条件的明确表达；优先验证局部协作与作者理解。热点仿写、批量生产和 SEO 不进入当前范围。复杂发布集成延后，先保证 Markdown 交付。

这种选择需要更细致的交互和质量评估，收益未必表现为最快生成。追问、结构和记忆也可能增加负担，因此必须进行真实任务验证。

## 重新讨论的条件

若观察显示核心协作不改善理解、作者不愿持续使用，或现有组合更有效，应调整交互或产品形态。若作者明确改变目标，再建立新的定位决策，保留此次方向的历史依据。
