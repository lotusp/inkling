# DEC-0002 MVP 在单台 Mac 本地运行

记录日期：2026-11-16。状态：部署目标已明确，具体技术实现为提案。依据：作者要求初步 MVP 在单台 Mac 本地运行，长期再考虑内容上云或多端协作。

## 范围

单用户、一个本地工作空间，文章、资料、会话和任务保存在本机。首版支持思考、写作、资料研究、作者风格、跨文章记忆与首个真实博客交付，完整范围见[V1 范围设计](../product/v1-scope.md)。

## 建议方案

采用浏览器工作台与一个本地 Node.js 服务进程。存储在文件快照与 JSON／JSONL、SQLite 两种候选中通过 POC 确定；SQLite 不是已冻结依赖。API 与任务调度同进程，后台执行不依赖浏览器页面存活。模型可通过 API 接入，模型完全离线运行仍待确认。

本地内容保存、版本冲突、备份恢复和 Mac 休眠后的任务处理进入 MVP 验收。一次性模型请求或网络连接不能跨机器休眠保证持续运行，产品需要清楚呈现中断和继续入口。

## 对原设计的调整

API 与 Worker 分进程改为同进程模块。运行框架先验证 Pi 加应用持久化，LangGraph 作为同任务对照。重启恢复以已保存成果和明确继续任务为起点，减少对无人值守自动恢复的首版依赖。Skills 保留内置方法，MCP 与 subagent 按具体需求接入。

先交付本地 Web 形态，再按真实使用需要增加桌面安装包。上述实现方案仍需 POC，本文不冻结 SDK 版本或桌面框架。

## 后续演进

业务对象保留稳定 ID 和版本，文件通过存储接口访问，凭据与业务数据分离。云备份、个人多设备同步和多人协作作为后续独立阶段，逐步补齐权限和冲突处理。

详细设计与验收见[单台 Mac 本地架构](../architecture/local-macos-mvp.md)。
