# Capability delta

## Purpose

新 capability 才保留本节：用至少 50 个字符说明它服务的作者任务、系统边界及可观察价值；已有 capability 沿用主规格 Purpose。

## ADDED Requirements

### Requirement: 简短的行为名称

系统 SHALL 满足具体可观察的行为约束。

#### Scenario: CAPABILITY-ACTION-001 正常行为

- **GIVEN** 明确的初始状态
- **WHEN** 用户或系统发起具体动作
- **THEN** 出现可验证的结果

按需使用 MODIFIED / REMOVED / RENAMED Requirements，删除不适用模板。
