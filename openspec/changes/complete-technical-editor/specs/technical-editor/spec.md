# technical-editor delta

## Purpose

让在本机写作的作者用现有稿纸编辑带结构的中文技术文稿，表达引文、代码、表格、图片、数学公式和图示。作者能检查导入结果、编辑预览的来源，并在撤销、切稿、重开或恢复版本后继续使用原有内容。

## ADDED Requirements

### Requirement: 在稿纸中编辑技术内容

编辑器 SHALL 通过按需展开的操作编辑技术格式，保留相邻文字、选区语义和改动历史。

#### Scenario: EDITOR-QUOTE-001 编辑段落引用
- **GIVEN** 正文包含普通中文段落
- **WHEN** 作者在该段落通过「段落格式」切换引用，或撤销、重做这次格式修改
- **THEN** 引用包围当前段落，相邻段落和文字保持原样；重复切换恢复普通段落，确认保存后重开保留所选格式。

#### Scenario: EDITOR-LINK-002 链接与代码
- **GIVEN** 正文有选中的中文文字及多行代码
- **WHEN** 作者添加、修改或移除链接，或设置代码块及语言后保存并重开
- **THEN** 选中文字、合法目标、代码换行与缩进均可找回；非法链接提示可修正，并保留原文。

#### Scenario: EDITOR-TABLE-003 编辑基础表格
- **GIVEN** 作者在可编辑的稿纸插入表格
- **WHEN** 填写含中文的单元格、增删行列、撤销并重开
- **THEN** 行列顺序、表头和单元格内容与最后一次确认保存的结构一致。

#### Scenario: EDITOR-PREVIEW-004 阅读公式与图示
- **GIVEN** 正文有公式源码和基础 Mermaid 流程图
- **WHEN** 作者离线查看预览，随后编辑源码或输入一段无法渲染的内容
- **THEN** 合法内容随编辑更新预览，错误定位到对应块并允许继续编辑；保存、恢复及复制时保留源码。

### Requirement: 本地图片随修订可用

系统 SHALL 将作者粘贴的本地图片保存在本工作空间，正文只在图片可用时确认相应引用。

#### Scenario: EDITOR-IMAGE-005 粘贴并找回图片
- **GIVEN** 作者将一张支持的本地图片粘贴到正文
- **WHEN** 保存、再次使用同图、重启服务，或从历史恢复含图的版本
- **THEN** 原插入位置可显示同一份图片内容，原文件移动也不影响文章，旧版本中的图片可读取。

#### Scenario: EDITOR-IMAGE-006 处理上传失败与迟到结果
- **GIVEN** 输出存储失败、文件格式或大小不受支持，或上传期间作者切稿、撤销或遇到只读状态
- **WHEN** 上传失败、重试或旧响应到达
- **THEN** 错误可见；不在另一篇文章或过期位置插图，不提交缺少资源的引用，已有正文和历史可继续使用。

### Requirement: 从文件导入独立主稿

系统 SHALL 允许作者先检查文本和 Markdown 的转换，再确认创建独立文章。

#### Scenario: EDITOR-IMPORT-007 确认导入
- **GIVEN** 当前稿有编辑内容，作者选择一份 UTF-8 文本或 Markdown 文件
- **WHEN** 预览后取消，或确认导入并在响应丢失后重试
- **THEN** 取消不创建文章；确认将标题和全文一次性写入独立新稿，重试只产生一份，原稿的编辑可找回。

#### Scenario: EDITOR-IMPORT-008 处理转换缺口
- **GIVEN** 输入有不支持的结构、外部资源引用、非法编码或超过大小上限
- **WHEN** 读取并预览文件
- **THEN** 可识别但无法转换的片段按原文呈现并列明位置，允许返回选择；无法完整读取或保存的文件给出原因，保持原稿和库中篇数。

### Requirement: 保留输入、旧稿和版本语义

系统 SHALL 在技术内容编辑、导航及历史操作中沿用稿纸的输入保护、只读和版本保证。

#### Scenario: EDITOR-OUTLINE-009 大纲与中文选词
- **GIVEN** 正文有重复的章节标题、选区或正在组合的中文输入
- **WHEN** 作者查看大纲、跳转、添加章节，或在候选窗内按回车选词
- **THEN** 跳转定位所选章节且不改正文和原选区；添加只生成一次标题及可写段落；选词不会提前提交格式或章节操作。

#### Scenario: EDITOR-ROUNDTRIP-010 新旧正文往返
- **GIVEN** 工作空间有 C03 旧修订、待恢复副本和含新技术节点的稿件
- **WHEN** 作者重开、保存、比较版本、恢复或处理并发冲突
- **THEN** 旧修订的内容和指纹可验证；新增节点、属性、源码及图片引用准确往返，预览可辨认改动。未知格式拒绝有损写入，归档稿保持只读。
