# C04 验收设计

## Scenario mapping

每个测试名以所列 ID 开头。E2E 使用 Playwright 的真实工作台、认证服务和临时 SQLite 工作空间，断言正文、已保存修订和可见交互。下面列出入口和夹具，新增用例随对应切片编写。

| ID | 层与入口 | 测试步骤与夹具 | 可观察断言 |
| --- | --- | --- | --- |
| EDITOR-QUOTE-001 | E2E，正文 → 段落格式 | 两个普通中文段落，对第二段引用、撤销、重做，再切换两次和重开 | 第一段保持普通，第二段在段落与引用之间可逆切换；文字、顺序及保存结构正确 |
| EDITOR-LINK-002 | 契约与 E2E，正文格式 | 对选区增加、更改和去除链接；试不支持的协议；保存带缩进和空行的有语言代码块 | 合法目标和源码重开一致；无效修改保留旧值及选区文本 |
| EDITOR-TABLE-003 | 契约与 E2E，稿纸表格 | 带表头的 2×2 中文表，编辑、增删、撤销、重开；经保存 API 送入非法行结构 | 保留表头、次序、单元格文字；非法结构拒写且 head 不变 |
| EDITOR-PREVIEW-004 | E2E，公式与 Mermaid 块 | 合法公式、两节点流程图、错误源码及外链输入；拦截外部网络，编辑并修复 | 渲染可见且无外部请求，错误可回改；重开保留原始源码，单独预览不增加修订 |
| EDITOR-IMAGE-005 | 附件 API、存储与 E2E，剪贴板 | 真 PNG/JPEG 字节、重复图片，粘贴后保存、移走源文件、重启服务、删图再恢复旧版本 | 已保存修订只含摘要；响应字节匹配原图，旧修订可显示 |
| EDITOR-IMAGE-006 | API、故障注入与 E2E | 伪装格式、过大/缺失图片、磁盘失败、未认证访问；延迟上传后切稿或撤销 | 非法写入不改变 head；原文保留，错误可修正，另一篇稿件不会出现迟到的图 |
| EDITOR-IMPORT-007 | 创建 API 与 E2E，文章库导入 | UTF-8 中文 .txt 和有一级标题/多种块的 .md；带未提交原稿；预览取消、确认、丢弃成功回包再重试 | 取消篇数不变；成功只多一篇，第一版含全文，原稿可找回 |
| EDITOR-IMPORT-008 | 转换单测与 E2E，导入预览 | 含未知指令、外部图和多字节文字的 Markdown，错误字节与超大文件 | 标注行号并保留原片段；拒绝无法保存的整份输入，库和当前稿不变 |
| EDITOR-OUTLINE-009 | E2E 与 Mac 手工，稿纸大纲 | 重名 h2/h3、已选段落、待输入章节；复跑 C03 大纲操作，再用真实中文候选窗选词 | 跳转到正确节点、选区及 head 不变；章节只添加一次；候选回车不抢提交 |
| EDITOR-ROUNDTRIP-010 | 存储/API、恢复与 E2E | C03 的已保存文档、旧浏览器副本、含全部新节点的中文稿。重开、并发编辑、命名、比较、版本恢复、只读归档 | 旧修订和 hash 保留；新格式完整读写，比较可看出更改，未知内容拒写且可救援 |

## Red 与已有行为

新增入口先跑指定 ID，留存因缺失行为而失败的断言，最小实现后重跑同一用例。已能读写的旧格式、手工添加章节及点击跳转先跑已有用例，分别核对新增断言。首个切片的 Red 应能定位到已打开的「段落格式」缺少「引用」。

## 必需检查与边界

- 切片内用 `node_modules/.bin/playwright test --grep EDITOR-QUOTE-001` 等 ID 筛选，涉及存储或转换时用 `corepack pnpm test`。用例名必须实际被发现。
- G2 执行 `corepack pnpm verify`、`corepack pnpm test:e2e`、`corepack pnpm test:storage-performance`。保存链路和千篇库继续满足既有门槛。以锁定依赖运行 Linux CI。使用隔离工作空间，测试图片、文章、配置均为合成夹具。
- Mac 上实测本次新增格式/章节与系统输入法选词，以及从系统剪贴板粘贴图片；记录实际系统、操作及结果。自动组合事件覆盖命令时序，真实手工结果另记。
- G2 汇总实际命令、日志、指纹和审阅结果。仅在所有必要检查完成后运行 Harness verify。本文是验收设计。
