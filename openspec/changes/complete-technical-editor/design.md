# C04 技术编辑器设计

## Context and boundaries

作者从现有稿纸完成编辑。「段落格式」承载正文命令，表格操作随表格出现，公式和图示在对应块内编辑或预览。文章库沿用一键新建，文件导入另设次级入口。使用键盘和 375px 窄屏时也能到达这些操作。已有大纲按正文 h2/h3 生成，跳转只滚动，添加章节走编辑器事务。[正式稿纸](../../../apps/web/src/App.tsx) · [文章库规格](../../../openspec/specs/article-library/spec.md)

Web 负责编辑、预览和文件转换。contracts 声明允许的文档、引用及命令。core 校验操作条件，adapters 管理工作空间文件及 SQLite，server 沿用本机认证、同源写保护和响应映射。[架构规范](../../../docs/engineering/code-architecture.md) · [DEC-0004](../../../docs/decisions/0004-article-storage-and-revisions.md)

## 编辑器选型更新

V1 正文采用 Muya，图片编辑沿用 Milkdown 的交互方式。只挂载一个正文内核。正式稿纸直接挂载 Muya，文章会话统一处理自动保存、修订、切稿与恢复。表格、公式和流程图保留可编辑源码，图片用工作空间摘要引用。之前的 1.1 至 2.3 保留为行为回归依据。

表格使用纸白表身、淡灰绿表头和细分隔线。工具图标默认墨灰，当前操作使用墨绿。Mermaid 的节点、边线、箭头、文字和标签沿用稿纸色板。原图像素与代码高亮独立于工具图标。尺寸、替代文字和图片标题随正文保存。

正式接入沿用工作空间鉴权、正文摘要、版本比较和草稿恢复。首版无需双写两套编辑器格式。替换后删除失去调用方的旧编辑逻辑。试写页的图片存储与工作空间附件验收分别记录。

## 已实现切片与后续契约

以下第 1 至 3 项记录 1.1 至 2.3 的实现基线。第 4、5 项描述正式附件与导入的目标。

1. **已有格式。** 引用沿用 StarterKit 的 blockquote 及单次编辑事务，格式菜单恢复原编辑位置。链接沿用 contracts 允许的目标协议，编辑器中显式修改或移除链接。代码块保留 language、缩进及换行。首个切片只增加「引用」菜单项。
2. **正文与版本。** 普通新稿和旧稿沿用正文版本 1，首次插入表格、公式或流程图时启用版本 2。删除整表后继续使用版本 2。升级后恢复旧稿时，以版本 2 写入新的恢复修订，来源修订保留原字节和校验值。IndexedDB 沿用已有数据库和副本格式，按草稿正文、已确认基线及未决请求各自携带的版本读取。救援下载、比较和恢复沿用同一正文结构。公式和流程图保存类型与源文本，图片保存工作空间内容摘要与替代文字。保留原有 2 MiB 正文及节点复杂度限制。
3. **技术块。** 浏览器使用与 StarterKit 同版的 `@tiptap/extension-table@3.34.0`。StarterKit 自带的节点缺少表格语义，TableKit 提供可撤销的单元格与行列编辑。「段落格式…」插入带表头的 2×2 表格，行列操作仅在表格内显示。保存接口校验矩形结构、跨行跨列和单元格内容，整篇所有表格展开后合计最多 50,000 格。数学和 Mermaid 优先按需加载本地渲染库，产物随应用构建，未使用预览时不加载。预览结果独立于正文历史；验收断网、错误后修复、内容输入约束、外部资源及主动内容隔离。引入依赖的切片记录实际版本、锁文件与构建影响。
4. **图片。** 使用专用的认证图片读写接口。初版支持 PNG、JPEG、GIF、WebP，单图上限 10 MiB。Fastify 对接收字节限长，sharp 在写入前核对格式并解码，限制为 3200 万像素，以内容摘要生成工作空间内的文件名。写临时文件、完成校验后原子落盘，再允许修订事务引用该摘要。服务端逐一验证正文引用属于当前空间且已落盘。相同字节可重放；删除正文中的图片只移除本次引用，保留历史和浏览器草稿可能用到的文件。磁盘回收策略留给涵盖全空间备份的变更。
5. **主稿导入。** 文章库选择一个 .txt 或 .md 文件，UTF-8 解码后预览标题、正文及带行号的转换提示。Markdown 首个一级标题可作稿名，否则取文件名；保留后续正文标题的层次或提示映射。纯文本按段落保留，Markdown 映射已支持结构，未支持的语法保留原片段；外链图片仅保留引用文本。确认时提交独立创建命令，沿用现有创建事务和 mutation ID，让初始修订直接包含全文。取消或拒绝输入时不改最近文章。原稿的导航协调器先保护本地未提交输入，再交接到返回的新稿。

### 公式源码与预览

「段落格式… → 插入公式」在选区末尾插入独立公式块。源码使用编辑器原生文本，换行、空格、撤销、复制和草稿恢复沿用正文机制。版本 2 的 `formulaBlock` 只含无样式文本，空白或尚未写完的 LaTeX 也可保存。单块的源码折叠状态和预览结果属于界面状态。

StarterKit 自带的代码块能保存文本，数学排版由浏览器按需加载的 `katex@0.19.1` 完成。应用从本机服务提供渲染模块，直接输出浏览器原生 MathML，免去外部样式与字体请求。同一页面加载过模块后，断开本机连接也能继续预览。限制单块预览输入为 8192 个 UTF-16 单元，限制宏展开和尺寸；超限或语法错误仍保留源码。渲染器拒绝外部资源和 HTML 命令。 [KaTeX 渲染选项](https://katex.org/docs/options)

### Mermaid 流程图源码与预览

「段落格式… → 插入流程图」沿用公式块的插入位置、源码折叠、撤销和复制行为。版本 2 的 `mermaidBlock` 保存原始文本，包括缩进、注释和未完成的语句。预览按 `graph` 或 `flowchart` 声明的方向绘制，支持基础节点形状、带标签的连线、分支与回路。超宽图在块内横向滚动。无效语句在块内提示，作者可就地修改。

官方浏览器包 `@mermaid-js/tiny@12.3.0` 随应用分发，第一次遇到可预览的流程图时才从本机加载，同页断开本机服务后仍可重新绘图。只将基础节点与连线语句交给严格模式的渲染器，先过滤整行注释，拒绝外部图片、点击动作、HTML 和配置指令。SVG 以图片显示。预览上限为 8192 个 UTF-16 单元、100 个节点及 100 条连线，超过时仍保存完整源码。渲染结果只用于当前编辑内容，过期结果会丢弃。[Mermaid 流程图语法](https://mermaid.js.org/syntax/flowchart.html)

## Failure and recovery

- 插图时记录文章、编辑会话和可随事务移动的插入位置。位置被删除、撤销、切稿或失去编辑权限后，忽略迟到结果；同处重试复用已落盘内容。进程退出可能留下孤立文件，已有修订继续引用原文件。
- 附件缺失、类型不符或配额错误时保留原稿，给出可重试或更换图片的操作。读取已受损的图时显示占位及诊断，不以空节点回存覆盖旧引用。
- 未知文档版本或节点继续触发拒绝写入。导入的丢包重试先核对原请求；跨标签冲突继续走既有保留副本、比较和恢复。只读历史使用同一套安全的节点显示。
- 中文组合输入期间保持焦点，选词回车不触发提交或技术块命令。大纲点击与查看预览不产生正文修订。C06 接入时另测真实会话的固定引用。

## Delivery

2.4 验收试写交互后，2.5 接入正式保存、版本、只读与大纲。用同一代 Muya 稿件在隔离的 SQLite 工作空间中验证已保存修订、IndexedDB 副本和离线恢复，随后接入工作空间图片与主稿导入。V1 发布前的开发数据格式可以替换。已有用户工作空间的清理或转换另行明确执行范围。
