# C04 技术文章编辑器

## Why

作者希望在同一张稿纸上完成一篇有引文、代码、图表和公式的中文技术文章，保存后能继续编辑。C03 已能从大纲添加和跳转章节。现有编辑器能保存引用与链接，但「段落格式」只提供加粗、小标题、列表和代码块；正文契约尚未支持图片、表格及公式。[V1 范围](../../../../docs/product/v1-scope.md) · [C04 路线图](../../../../docs/engineering/v1-change-roadmap.md)

## What Changes

- 沿用稿纸和按需展开的格式菜单，接入引用、链接、技术块、撤销重做与离线预览。验证原有大纲、键盘操作和中文输入。
- 支持粘贴本地图片，正文修订引用工作空间内的附件。历史版本和恢复副本仍可引用其图片。
- 从文章库导入 UTF-8 文本或 Markdown 为独立新稿。作者可先查看转换结果及未支持的内容，再确认创建。

- 正文内核采用 Muya。图片选取、截图粘贴、拖入、原位编辑和拖柄缩放借鉴 Milkdown 的按需交互。表格、操作图标与基础流程图使用稿纸配色。

## Non-goals

模型对话及讨论引用的创建归 C06，资料库导入归 C08，AI 章节重排归 C10，导出包与发布归 C14/C15。

## Capabilities

### New Capabilities

`technical-editor` 规定技术内容的创建、预览、持久化往返、图片粘贴、主稿导入和大纲交互。

### Modified Capabilities

沿用现有文章库、持久化和修订规格的保证。扩展的节点、附件和导入行为在新规格描述。

## Impact

涉及 Web 编辑器、共享正文校验、草稿及版本比较、本机认证 API 与附件存储。沿用 JSON 主稿和 SQLite 修订。新增依赖按实际使用分片引入，首个引用切片可直接复用 StarterKit。[存储决策](../../../../docs/decisions/0004-article-storage-and-revisions.md)
