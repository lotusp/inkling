# article-library delta

## Purpose

为个人作者在同一本机工作空间中管理多篇技术文章，提供稳定身份的导航、标题与标签查找和可逆生命周期；复用已有正文版本与恢复协议，避免切换或整理文章时丢失个人输入，并支持安全重开最近写作位置。

## ADDED Requirements

### Requirement: 文章库与兼容迁移

系统 SHALL 支持稳定文章 ID 的多稿件列表和显式新建，沿用会话保护与事务去重；迁移不得改变原有正文与版本。

#### Scenario: LIBRARY-MIGRATE-001 已有空间升级

- **GIVEN** 存在 C02 schema 2 的稿件、历史、命名和请求记录
- **WHEN** 新版本首次打开并再次重开
- **THEN** 增量迁移只执行一次，原 ID、正文、hash、历史、名称和已提交请求保持；迁移失败回滚且不启动替代空库

#### Scenario: LIBRARY-CREATE-002 显式新建多篇文章

- **GIVEN** 工作空间已有文章
- **WHEN** 作者新建另一篇，或重复发送同一新建请求
- **THEN** 新请求创建独立文章与初始修订；重放返回原结果且不重复创建或改变后来选择的文章；旧文章完整保留

#### Scenario: LIBRARY-LIST-003 分页文章列表

- **GIVEN** 有多篇含同名或未命名标题的文章
- **WHEN** 作者浏览或加载下一页
- **THEN** 按设计中的稳定顺序显示 ID 对应的标题和状态，不把全文带入列表；无重复/遗漏，空态与读取失败明确区分

### Requirement: 导航与正文隔离

系统 SHALL 在打开、新建和切换文章时保护旧稿未确认输入；每个标签页保持自己的文章会话，迟到结果不能作用于另一篇文章。

#### Scenario: LIBRARY-OPEN-004 打开与最近文章

- **GIVEN** 列表中有可访问文章
- **WHEN** 作者打开并重启页面
- **THEN** 显示该 ID 的正文及历史，最近文章可重开；其他标签已打开的文章不被全局最近指针主动切换

#### Scenario: LIBRARY-SWITCH-005 未保存与迟到请求

- **GIVEN** 本页有未保存输入、未决请求、中文选词、冲突或待选择恢复副本
- **WHEN** 作者请求切换或新建
- **THEN** 先完成/确认旧稿保存或明确保留副本；无法安全保留时阻止切换；候选期间不切换，旧请求结果不覆盖新文章

#### Scenario: LIBRARY-POSITION-012 恢复编辑位置

- **GIVEN** 作者在某篇稿件保存编辑位置后切换或重开
- **WHEN** 再次打开该稿件
- **THEN** 同一文章且同一修订可恢复选择/滚动位置；版本已变化或位置非法时安全回到文首，不改正文

### Requirement: 标题与标签整理

系统 SHALL 将重命名作为正文标题的版本化修改；标签独立于正文，元数据更新校验基线并支持幂等。

#### Scenario: LIBRARY-RENAME-006 重命名不产生第二份标题

- **GIVEN** 文章已有正文和修订
- **WHEN** 作者在文章库重命名，或另一标签先保存
- **THEN** 通过原正文 CAS 保存更新唯一标题、保留 ID/正文/历史；旧基线拒绝，列表与编辑器不互相覆盖

#### Scenario: LIBRARY-TAGS-007 标签与元数据竞争

- **GIVEN** 两标签读取相同元数据版本
- **WHEN** 分别修改文章标签或重复相同请求
- **THEN** 第一份提交推进元数据版本，过期修改拒绝，重放不重复；中文标签规范化、去重及长度/数量限制生效

#### Scenario: LIBRARY-FIND-008 标题与标签查找

- **GIVEN** 存在不同标题、标签及生命周期的稿件
- **WHEN** 按标题片段和标签过滤并翻页
- **THEN** 只返回当前状态下的匹配文章，中文可查、百分号等按字面处理；查找不改正文，不声称全文搜索

### Requirement: 归档与回收站

系统 SHALL 提供可逆的归档与移入回收站，保留文章身份、历史与本机恢复副本；不可编辑状态拒绝新的正文写入，不执行永久删除。

#### Scenario: LIBRARY-ARCHIVE-009 归档与重新编辑

- **GIVEN** 文章处于活动状态且本页输入已处理
- **WHEN** 作者归档，或另一标签仍尝试保存
- **THEN** 从活动列表移出，仍能只读查看历史；新保存/恢复/命名被拒绝并保留输入；取消归档后可继续编辑

#### Scenario: LIBRARY-TRASH-010 移入回收站

- **GIVEN** 文章可见且作者已查看删除确认
- **WHEN** 确认移入回收站，或取消
- **THEN** 确认后保留全部正文与历史，当前指针不继续指向回收站项；取消无变化；过期状态请求拒绝且不自动丢弃副本

#### Scenario: LIBRARY-RESTORE-011 从回收站恢复

- **GIVEN** 文章从活动或归档状态进入回收站
- **WHEN** 作者选择恢复
- **THEN** 回到删除前状态，原 ID/标签/正文/历史完整保留；重复请求幂等，不复制稿件

#### Scenario: LIBRARY-FAILURE-013 文章库失败边界

- **GIVEN** 请求未授权、路径/载荷非法或存储异常
- **WHEN** 请求列表、新建、导航或修改生命周期
- **THEN** 延续会话与同源校验，不泄漏文章；非法输入拒绝，写失败不提交半状态，UI 保留旧稿并给出可恢复提示
