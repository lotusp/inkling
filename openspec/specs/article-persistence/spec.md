# article-persistence Specification

## Purpose
为本机作者保存唯一权威稿件，并明确服务端提交、浏览器恢复副本和未保存输入的不同状态，使重试、并发编辑、离线和进程失败不会静默覆盖内容。

## Requirements

### Requirement: 正文与保存契约

系统 SHALL 保存带 schema 版本的标题与结构化正文，采用稳定文章 ID、base revision 与 mutation ID；只在原子提交成功后确认保存，正文、head 与成功请求记录保持一致。

#### Scenario: ARTICLE-CREATE-001 首次创建与重开

- **GIVEN** 默认工作空间尚无文章
- **WHEN** 作者在首次进入时选择开始写作，或重新打开已有工作空间
- **THEN** 首次创建唯一的初始文章与初始版本；并发初始化不重复创建，随后打开当前文章

#### Scenario: ARTICLE-SAVE-002 保存并重启

- **GIVEN** 文章已打开
- **WHEN** 作者编辑中文标题、正文及当前支持的格式，等待保存后重启页面和服务
- **THEN** 内容与格式一致，显示正确已保存版本，未收到提交确认前不显示已保存

#### Scenario: ARTICLE-RETRY-003 响应丢失后的重试

- **GIVEN** 请求已经提交但响应丢失
- **WHEN** 客户端以相同 mutation ID 和原始载荷重试或查询结果
- **THEN** 返回原结果，不重复创建版本；即使当前 head 已推进也能查到原提交

#### Scenario: ARTICLE-KEY-004 幂等键误用

- **GIVEN** mutation ID 已对应成功请求
- **WHEN** 以相同 ID 提交不同文章、基线、内容或操作
- **THEN** 返回明确冲突，不覆盖原记录或稿件

### Requirement: 编辑并发与客户端恢复

系统 SHALL 保留未确认输入，拒绝过期基线，不以迟到响应或其他标签页内容替换作者当前稿；离线副本不得自动成为服务器权威。

#### Scenario: ARTICLE-RACE-005 保存期间继续输入

- **GIVEN** 一份保存请求正在处理
- **WHEN** 作者继续输入，随后较旧请求成功返回
- **THEN** 只推进确认版本，不替换最新正文，不清除更新的恢复副本，也不错误显示全部已保存

#### Scenario: ARTICLE-CONFLICT-006 两个标签页写同一基线

- **GIVEN** 两个标签页从相同版本打开
- **WHEN** 先后提交不同内容
- **THEN** 仅先提交成功；后提交返回冲突并保留两边内容，作者查看差异后用新基线显式合并，不能强制静默覆盖

#### Scenario: ARTICLE-LOCAL-007 离线与恢复副本

- **GIVEN** 工作台已加载，浏览器副本已成功写入，服务暂时不可达
- **WHEN** 作者继续输入、刷新仍可加载的页面或重开服务，并选择恢复草稿
- **THEN** 先核对未决 mutation 和最新 head，再恢复待提交输入；有新版本则进入冲突；多个标签页副本不相互覆盖

#### Scenario: ARTICLE-IDB-008 浏览器存储失败

- **GIVEN** 浏览器恢复副本不可写或已满
- **WHEN** 作者编辑或尝试离开
- **THEN** 明确显示本机恢复副本不可用，保留内存正文与救援下载入口，不声称离线稿已安全保存

### Requirement: 失败与兼容边界

系统 SHALL 在写入失败、容量或格式不支持时保留现有权威数据和可恢复输入，禁止静默重置、截断或丢弃未知节点。

#### Scenario: ARTICLE-WRITE-009 提交失败

- **GIVEN** 已有有效修订
- **WHEN** 保存遇到磁盘满、权限或 I/O 错误
- **THEN** 不推进 head 或显示已保存，保留旧修订和待提交内容，并允许核对、重试或下载恢复稿

#### Scenario: ARTICLE-CRASH-010 提交边界中断

- **GIVEN** 保存正处于事务边界
- **WHEN** 进程在提交前或提交后但响应前终止，随后重开并重试
- **THEN** 分别读取旧提交或完整新提交，head、修订与去重记录一致，重试不产生重复修订

#### Scenario: ARTICLE-SCHEMA-011 格式不受支持

- **GIVEN** 输入含未知 schema、节点、属性或超出大小/深度限制
- **WHEN** 加载或提交正文
- **THEN** 明确拒绝不兼容写入，保留原数据，不静默删掉未知内容后保存

#### Scenario: ARTICLE-CORRUPT-012 内容损坏

- **GIVEN** 权威稿件 hash 不匹配或存储结构损坏
- **WHEN** 启动或读取版本
- **THEN** 阻止受影响写入，提供诊断与可验证旧版本的救援入口，不自动以旧稿覆盖当前 head

#### Scenario: ARTICLE-QUOTA-013 容量保护

- **GIVEN** 文章历史达到设计容量门槛
- **WHEN** 产生新内容修订
- **THEN** 提前提示容量；达到上限时拒绝新增正文存储并保留草稿，不自动删除命名版本或静默截断
